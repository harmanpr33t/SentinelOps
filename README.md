# SentinelOps
AI-Powered Incident Intelligence & Observability Platform.

Stack: React/Vite, Node.js/Express, Python/FastAPI, PostgreSQL-ready architecture, real-time observability UI.

## Frontend
cd frontend
npm install
npm run dev

## Backend
cd backend
npm install
npm start

## AI
pip install -r ai/requirements.txt
uvicorn main:app --app-dir ai --reload
